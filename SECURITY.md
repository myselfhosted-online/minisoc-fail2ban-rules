# Security Policy

## Reporting a security issue

Please do not publish secrets, credentials, private tokens, private log data, or exploit material that could endanger a real system.

For problems in these detection rules, open a GitHub issue with sanitized logs and enough context to reproduce the false positive or false negative.

## Scope

This repository contains defensive Fail2Ban/MiniSOC detection logic and sanitized research samples. It does not intentionally publish credentials, private keys, session tokens, or confidential application data.

## Responsible disclosure

If you discover that a public sample accidentally contains sensitive data, report it immediately and avoid redistributing it.
