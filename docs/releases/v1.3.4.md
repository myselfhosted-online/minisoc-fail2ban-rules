# MiniSOC Fail2Ban Rules v1.3.4 (release candidate)

**Maintenance hotfix — preserving incompatible local MiniSOC signature databases**

## Reported failure

During a real Debian v1.3.3 dry run, two customized Fail2Ban filters were correctly preserved, but the updater then stopped at `Invalid regex /etc/minisoc/signatures-v2.db:1: unbalanced parenthesis at position 1`. This came from preflight validation of the **existing local** database, not from any finding that the bundled v1.3.3 signatures were invalid.

## Fix

- Continue the dry run and clearly report incompatible local signature databases as `WARNING PRESERVED`, showing the original diagnostic.
- Keep the default real upgrade fail-closed. `--preserve-custom-signatures` is a separate explicit opt-in for a **partial** update; the database is then left byte-for-byte untouched.
- If both custom filters and a local signature database are incompatible, require **both** preservation flags. Neither data source is rewritten.
- Validate all bundled signature patterns even when the local database cannot be parsed. New release signatures with invalid regexes, and conflicting existing signature IDs, remain hard errors.
- Keep backups, post-write Fail2Ban validation, rollback and preflight checks on every file that is actually modified.

## Upgrade instructions

From the extracted **v1.3.4** archive, first review the plan:

```bash
sudo bash ./install/install.sh --dry-run
```

Only if the plan reports both kinds of incompatibility, and after reviewing the local MiniSOC database with its maintainer, explicitly choose a partial update:

```bash
sudo bash ./install/install.sh --dry-run --preserve-custom-filters --preserve-custom-signatures
sudo bash ./install/install.sh --preserve-custom-filters --preserve-custom-signatures
sudo fail2ban-client -t
```

**Important:** A partial update does *not* activate new filter rules in preserved filters, or new MiniSOC detection signatures in a preserved database. This change is deliberately conservative and does not claim to repair an unknown live regex. Publishing the release does not deploy it to production.
