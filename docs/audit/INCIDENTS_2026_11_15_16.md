## Parent incident 2 — 16 November 2026, 05:06 CET

Observed: **2 Fail2Ban jail alerts**, one source, **6 distinct HTTP requests**, **404 ×6**. Both `nginx-skanery` and `nginx-dev-honeypot` alerts repeated the same six requests. Classification in alerts: `generic-vulnerability-scan — MEDIUM`.

Targets: `/config.json`, `/config/config.json`, `/config.yaml`, `/client_secrets.json`, `/credentials.json`, `/credentials.yml`.

Interpretation: coordinated configuration/credential enumeration. Individual common configuration files are not necessarily secrets, so this is a behavior family requiring burst correlation, not a reason to ban a single legitimate `config.json` request. HTTP 404 reports no resource at these paths in the responses shown; it is not proof of comprehensive safety.

## Deduplication check

**5 raw jail alerts → 2 parent incidents → 24 unique HTTP request events.** A sanitized JSON test fixture makes this calculation reproducible and verifies no double-counting when two jails report identical events.

## Deployment notes

Public v1.3.1 lacks production jails `nginx-highconf` and `nginx-fake-searchbots`. Their existing definitions remain outside this patch. Do not invent or overwrite their rules from this alert alone; obtain and audit the live configurations separately before any rollout.
